# Change Log

## 1.0.0

- Introduced the HNNX ONNX graph workbench for VS Code, including Remote SSH,
  Dev Container, and Kubernetes workspaces.
- Added AIMET legacy, 1.x, and 2.x encoding visualization with mixed-precision
  badges, precision propagation, and explicit or derived quantization ranges.
- Added NVIDIA ONNX GraphSurgeon-backed graph editing, validation, shape
  inference, undo/redo, and Save As.
- Added first-run settings for theme, encoding discovery and visibility,
  automatic shape inference, and the GraphSurgeon Python environment.
- Preserved ONNX editor tabs across file switches and added neighboring
  encoding auto-discovery, reload, detach, and visibility controls.
